# Contributing

Issues and pull requests are welcome at https://github.com/tana3d/studio.
Discuss substantial changes in an issue first. Describe the user-facing behavior and the checks you ran. Run the checks documented in README.md before submitting.

Preserve the bundled editor's controls, keep native credentials out of the webview, and include current scene and library metadata automatically in agent requests through Rixse. Keep bulky geometry, animation frames and file contents local, and route accepted edits through the shared undo history. Do not restore the old file index, global launcher shortcuts, or search services.

Desktop contributions use Apache-2.0; editor contributions use MIT.
